## 🌐 How to Publish on GitHub Pages

Follow these steps to host the website for free:

1. **Create a GitHub account** at [github.com](https://github.com) (if you don't have one)

2. **Create a new repository:**
   - Click the `+` button → New repository
   - Name it: `muzaffargarh-skills-academy`
   - Set it to **Public**
   - Click **Create repository**

3. **Upload your files:**
   - Click **Add file** → **Upload files**
   - Drag and drop all project files (`index.html`, `style.css`, `script.js`, `README.md`, `images/`)
   - Click **Commit changes**

4. **Enable GitHub Pages:**
   - Go to **Settings** → **Pages**
   - Under **Source**, select **Deploy from a branch**
   - Set branch to **main** and folder to **/ (root)**
   - Click **Save**

5. **Your website will be live at:**
   ```
   https://your-username.github.io/muzaffargarh-skills-academy/
   ```
